PosterBlack.woff2 is the Latin subset of Noto Sans Display ExtraCondensed
Black (weight 900, width 62.5%), downloaded from Google Fonts
(https://fonts.google.com/specimen/Noto+Sans+Display) for this app's
poster lettering. It is licensed under the SIL Open Font License, Version
1.1 (https://openfontlicense.org), which allows it to be shipped with
this app. Noto Sans Display is Copyright 2012 Google Inc.

The file shipped here was subset locally with fontTools (pyftsubset) to
Latin basic + Latin-1 supplement + general punctuation, so it covers the
glyphs this app's titles and taglines use and nothing more.
